# TuxFF Models

Experimental machine-learning models for NFL fantasy-football projections. The current implementation uses a PyTorch **mixture density network (MDN)** to predict a probability distribution—not just a single point estimate—for a player's season-long half-PPR fantasy points.

> [!NOTE]
> This repository is an exploratory research project. It does not currently expose a packaged training pipeline or production inference API.

## How it works

The project currently follows this workflow:

1. Load historical player and season statistics from `data/fantasy_data.csv`.
2. Build features from each player's previous three seasons.
3. One-hot encode player positions and write the model-ready data to `data/data_mdn.csv`.
4. Split and standardize the data, then train an MDN to estimate a Gaussian mixture over half-PPR points.
5. Inspect the predicted distribution and calculate percentile outcomes for an individual player-season.

The prepared dataset contains 65 model features. The current training notebook uses three hidden layers (`256`, `128`, and `64` units), five Gaussian components, and dropout.

## Data

The included data is derived from these Kaggle datasets:

- [NFL Fantasy Data, 1970–2024](https://www.kaggle.com/datasets/heefjones/nfl-fantasy-data-1970-2024)
- [NFL Stats, 1999–2022](https://www.kaggle.com/datasets/philiphyde1/nfl-stats-1999-2022)

`fantasy_data.csv` contains 29,369 player-season records. The preprocessing notebook selects passing, rushing, receiving, availability, experience, and accolade fields, then creates one-, two-, and three-season lag features. Seasons with no prior history at all are removed. The resulting `data_mdn.csv` contains 22,341 rows and uses `Points_half-ppr` as its target.

Review the source datasets' licenses and terms before redistributing or using the data commercially.

## Setup

Python 3.10 or newer is recommended. Create a virtual environment and install the notebook dependencies:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install jupyter matplotlib numpy pandas scipy scikit-learn torch
```

PyTorch installation can vary by operating system and accelerator. If needed, use the command generated by the [official PyTorch installer](https://pytorch.org/get-started/locally/).

## Usage

Start Jupyter from the repository root:

```bash
jupyter lab
```

### 1. Prepare the data

The model-ready dataset is already committed at `data/data_mdn.csv`. To rebuild it, open `scripts/nfl_data_process.ipynb` and run the cells in order.

Before running the notebook, replace its Windows-specific input and output paths with repository-relative paths:

```python
data = pd.read_csv("data/fantasy_data.csv")
# ...
data_MDN.to_csv("data/data_mdn.csv", index=False)
```

### 2. Train the model

Open `models/mixture_density_network/v1/MDN_train.ipynb`. Update its dataset path to point to the repository's prepared data, for example:

```python
filepath = "../../../data/data_mdn.csv"
```

The notebook saves fitted scalers and a PyTorch checkpoint. Create its output directories before running the training cell:

```bash
mkdir -p models/mixture_density_network/v1/saved_models/scalers/feature_scaler
mkdir -p models/mixture_density_network/v1/saved_models/scalers/target_scaler
mkdir -p models/mixture_density_network/v1/saved_models/save_dicts
```

Run the notebook from its own directory so its `from MDN import ...` imports and relative output paths resolve correctly. Training automatically selects CUDA, Apple Metal (`mps`), or CPU, in that order of availability.

### 3. Explore a prediction

The final cells of `MDN_train.ipynb` select a player by `Key` and `Year`, then:

- output the mixture weights, means, and standard deviations;
- plot the component and combined probability densities; and
- sample the mixture to estimate the 10th, 25th, 50th, 75th, and 90th percentile outcomes.

Change `player_key` and `year` to inspect another row in the prepared dataset.

## Model details

`MDN.py` provides:

- `load_data`: an 80/20 train/test split plus independent feature and target standardization;
- `nfl_dataset`: a PyTorch `Dataset` wrapper;
- `MDN`: a feed-forward network producing mixture weights (`pi`), means (`mu`), and positive standard deviations (`sigma`); and
- `train_model`: training and validation loops using negative log-likelihood and gradient clipping.

The saved checkpoint includes the model state, architecture settings, training settings, loss histories, timestamps, and paths to the fitted scalers.
